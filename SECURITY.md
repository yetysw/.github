# Security

This policy applies to every project of the yety organization. A project may add details in its own `SECURITY.md`, which then takes precedence for that project.

## Report a vulnerability

Please do not open a public issue. Write to [hello@yety.ch](mailto:hello@yety.ch) with the project concerned, the affected version, the steps to reproduce and the impact you see.

We aim to acknowledge a report within 7 days and to give a first assessment within 14 days. These are goals rather than guarantees. We credit reporters who want to be named.

## Supported versions

The latest release of each project and its default branch. Older versions do not get fixes.
